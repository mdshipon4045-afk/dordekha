# ডোমেইন ও হোস্টিং — সেটআপ গাইড (বাংলায়)

> সাইট এখন `dordekha.shouroveh9.workers.dev`-এ চলছে। ডোমেইন বসালে সাইটের ঠিকানা
> হবে `dordekha.ডোমেইন` — ইউজার-বান্ধব, Google-এ ইনডেক্সযোগ্য, আর ইমেইল ঠিকানা যোগ করা যাবে।

> **মালিকের কাজ: ২টি।** বাকি সব স্ক্রিপ্ট করবে।

## ধাপ ১ — Cloudflare API টোকেন বানান (২ মিনিট, ফ্রি)

টোকেনটা দরকার কারণ `wrangler`-এর লগইনে ডোমেইন যোগ করার permission নেই।

1. খুলুন: **https://dash.cloudflare.com/profile/api-tokens**
2. **Create Token** → **Create Custom Token**
3. ভরুন:

   | ঘর | মান |
   |---|---|
   | Token name | `dordekha-domain-setup` |
   | Permissions | **Zone** → **Edit** · **Account** → **Account Settings** → **Read** |
   | Zone Resources | Include → Specific zone → *(পরে জোন যোগ হলে)* **All zones from an account** → `dordekha` account |
   | Account Resources | Include → Specific account → `dordekha` |

4. **Continue to summary** → **Create Token**
5. **টোকেনটা কপি করে রাখুন** (একবারই দেখা যায়)।

> ⚠️ টোকেনটা কাউকে দেবেন না। শুধু আমাকে (OpenCode) দিন — আমি এখানেই ব্যবহার করে ফেলব, তারপর টোকেনটা মুছে দেবেন।

## ধাপ ৩ — টোকেনটা আমাকে দিন

এক লাইনে:

```
node tools/setup-domain.mjs dordekha.eu.org <আপনার-টোকেন>
```

**এই স্ক্রিপ্ট যা করবে (সব নিজে থেকে):**
1. Cloudflare-এ জোন তৈরি করবে
2. রেজিস্ট্রিতে দেওয়ার জন্য **দুটি nameserver** বের করে দেবে
3. Worker-কে নতুন ডোমেইনে সাথে যুক্ত করবে (`workers/domains`)
4. `SITE_ORIGIN` বদলে দেবে (canonical, sitemap, llms.txt, MCP উদ্ধৃতি — সব নতুন ডোমেইনে যাবে)
5. ডিপ্লয় করবে
6. যাচাই করবে: `/health`, canonical লিংক, পেজে ডোমেইনের উল্লেখ

## ধাপ ৪ — যেটা শুধু মালিকই করতে পারবে

**eu.org নিলে:** রেজিস্ট্রির ফর্মে টোকেন নয়, **nameserver** বসাতে হবে। স্ক্রিপ্ট যে দুটো
nameserver দেখাবে, সেগুলোই বসাতে হবে। তারপর রেজিস্ট্রি একটা **কনফার্মেশন ইমেইল** পাঠাবে — সেটায়
উত্তর দিতে হবে। (এই একটা ইমেইল ছাড়া আর কিছু মানুষের করার নেই।)

**js.org / is-a.dev নিলে:** GitHub-এর অ্যাকাউন্ট দরকার (এটা আপনার জন্যই লাগবেই — MCP Registry
পাবলিকেশনের জন্যও GitHub লাগবে)।

## হোস্টিং — আলাদা কাজ নেই

সাইট ইতিমধ্যেই **Cloudflare Workers-এ** (ফ্রি প্ল্যান) চলছে: D1 + KV + ক্রন + ইমেইল।
ডোমেইন বসালে শুধু ঠিকানা বদলাবে, **হোস্টিং একই থাকবে** — কোনো মাইগ্রেশন, কোনো খরচ, কোনো নতুন
প্ল্যাটফর্ম নয়। Worker-এর জন্য `*.workers.dev` থাকে খুব ভালো, কারণ:

- ফ্রি প্ল্যানে ১০০,০০০ রিকোয়েস্ট/দিন, ১ মিনিটের CPU
- D1: ৫ লক্ষ সারি পড়া + ১ লক্ষ সারি লেখা/দিন
- KV: ১ লক্ষ পড়া, ১০০০ লেখা/দিন
- SSL সার্টিফিকেট ক্লাউডফ্লেয়ার নিজে দেয় (Let's Encrypt — ফ্রি)

**যা লাগবে না:** VPS, cPanel, ডোমেইন হোস্টিং, SSL কেনা, কোনো পেমেন্ট গেটওয়ে, কোনো পেইড প্ল্যান।

ডোমেইন বসানোর পরে ইমেইল ঠিকানা যোগ করা যাবে:

- **পাঠানোর জন্য:** Zoho Mail-এর ফ্রি প্ল্যান (কাস্টম ডোমেইন, ১ ব্যবহারকারী) অথবা
  ব্রিভো/SendGrid-এর ফ্রি SMTP রিলে (দিনে ৩০০/১০০ পর্যন্ত) — উভয়েই ফ্রি টায়ারেই
- **গ্রহণের জন্য:** Cloudflare Email Routing (সম্পূর্ণ ফ্রি) — `contact@dordekha.eu.org`
  আপনার Gmail-এ চলে আসবে

**⚠️ আইনি দিক:** বাংলাদেশে ট্রেড লাইসেন্স ছাড়া বাণিজ্যিক ইমেইল (বিশেষত কেনাকাটার ইমেইল) পাঠানো
ঝুঁকিপূর্ণ। লাইসেন্স চিঠি না যাওয়া পর্যন্ত **শুধু গ্রহণ**-এর পথ চালু রাখাই নিরাপদ।
