password-এর পাশে **Delete** 🗑️

**২. Cloudflare API token বাতিল/বদল:** **https://dash.cloudflare.com/profile/api-tokens** →
`dordekha-setup` → **Revoke** (এখন দরকার নেই, কিন্তু চ্যাটে লেখা আছে)

> দুটোই এখন চ্যাটের ইতিহাসে স্থায়ীভাবে লেখা আছে — তাই কাজ শেষে বাতিল করা ভালো।
> আমি কোনো password রিপোজিটরিতে লিখিনি — সব `.secrets.env` ফাইলে, যেটা git-ignored
> (`git status` পরিষ্কার ✅)।
