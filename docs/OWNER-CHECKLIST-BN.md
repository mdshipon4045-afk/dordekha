## ধাপ ১ — লাইসেন্স চিঠির ৪টি ফাঁকা → ✉️ পাঠানো (৫ মিনিট)

**এটাই আয়ের দরজা।** লাইসেন্স ছাড়া বাণিজ্যিক বিক্রি আইনি ঝুঁকি — তাই কোডেও paid key
বন্ধ করে দিয়েছি (`LICENCE_GRANTED` ছাড়া paid plan বানানো যায় না)।

**চিঠি:** `docs/licence-letter-FINAL.txt` — পুরো লেখা, প্রেরকের ইমেইল, মোবাইল ও তারিখ
আমি বসিয়ে দিয়েছি। **চারটি জায়গা** শুধু আপনার:

| ফাঁকা | কী লাগবে |
|---|---|
| `⟦প্রেরকের নাম⟧` | আপনার পূর্ণ নাম |
| `⟦পিতার নাম ও ঠিকানা⟧` | পিতার নাম + আপনার ঠিকানা |
| `[সই]` | হাতে লেখা সই (ছবি) বা টাইপ করা নাম |
| `[পরিচয়পত্র নম্বর]` | আপনার NID |

**প্রেরক:** `shourovehasan23@gmail.com` → **প্রাপক:** `dg@dam.gov.bd` (মহাপরিচালকের
দপ্তর) + অনুলিপি `chief@dam.gov.bd` (অফিসিয়াল সাইটের ঠিকানা)।

**আমার কাজ:** আপনি ফাঁকা ৪টি পূরণ করে বলবেন **"পাঠাও"** → আমি চিঠিটি + এক পাতার পরিচিতি
সংযুক্ত করে **আপনার Gmail থেকেই পাঠিয়ে দেব** (SMTP যাচাই করা ✅)।

## ধাপ ৩ — Cloudflare-এ ডোমেইন যোগ করুন (২ মিনিট) 🔑

> **বদলে গেছে:** API token দিয়ে জোন বানানো যায় না — Cloudflare-এর API `account.zone.create`
> permission চায়, আর ড্যাশবোর্ডের টোকেন UI-তে সেটি নেই
> (ত্রুটি: `Requires permission "com.cloudflare.api.account.zone.create"`)। তাই একটি ক্লিকে
> ড্যাশবোর্ডে জোন বানাতে হবে; **বাকি সব আমি API দিয়ে করব**।

**কীভাবে:**
1. **https://dash.cloudflare.com/87013ff9a4f44a15adab832cc34f0c68** → **Add a domain**
2. `dordekha.dpdns.org` লিখুন → **Free** প্ল্যান → **Continue**
3. Cloudflare যে **দুটো nameserver** দেখাবে, সেগুলো কপি করে রাখুন — ধাপ ৪-এ লাগবে

**আমার কাজ:** Worker-কে custom domain-এ যুক্ত করা → DNS/MX রেকর্ড → `SITE_ORIGIN` বদলানো →
ডিপ্লয় → যাচাই।

## ধাপ ৪ — DigitalPlat-এ ডোমেইন রেজিস্টার (২ মিনিট) 🌐

**কেন:** `dordekha.dpdns.org` — ফ্রি, NS ডেলিগেশন অনুমোদিত, আর Cloudflare সরাসরি জোন
হিসেবে নেয় (কোনো প্রক্সি লাগবে না, Worker নিজেই সার্ভ করবে)।

**কীভাবে:**
1. **https://dash.domain.digitalplat.org** → লগইন (অ্যাকাউন্ট বানিয়েছেন ✅)
2. `dordekha.dpdns.org` রেজিস্টার করুন
3. ধাপ ৩-এ কপি করা **দুটো Cloudflare nameserver** এখানে বসান
4. (ঐচ্ছিক) ভেরিফিকেশন ইমেইল আসলে আমি পড়ে ক্লিক করে দেব ✅

**আমার কাজ:** জোন active হওয়ার পর — Worker-এর custom domain + SSL + **MX রেকর্ড (ইমেইলের
জন্য)** + `SITE_ORIGIN` + ডিপ্লয় + যাচাই।
