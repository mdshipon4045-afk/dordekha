## ধাপ ১ — Cloudflare API token (২ মিনিট) 🔑

**কেন:** ডোমেইনটা ক্লাউডফ্লেয়ারে যোগ করতে `zone.create` permission লাগে, যা
`wrangler`-এর লগইনে নেই (আমি এই কাজে চেষ্টা করে ৪০৩ পেয়েছি)।

**কীভাবে:**
1. খুলুন → **https://dash.cloudflare.com/profile/api-tokens**
2. **Create Token** → **Create Custom Token**
3. এভাবে ভরুন:

   | ঘর | মান |
   |---|---|
   | Token name | `dordekha-setup` |
   | Permissions | **Zone** → **Edit** · **DNS** → **Edit** · **Account** → **Account Settings** → **Read** |
   | Zone Resources | **All zones from an account** → `dordekha` |
   | Account Resources | **All accounts from an account** → `dordekha` |

4. **Continue to summary** → **Create Token** → **Copy the token**

**আমার কাজ:** টোকেনটা দিলেই আমি এক লাইনে পুরো ডোমেইন সেটআপ করে দেব:
```
node tools/setup-domain.mjs dordekha.dpdns.org <টোকেন>
```
→ জোন বানাই → NS বের করি → Worker-কে ডোমেইনে যুক্ত করি → `SITE_ORIGIN` বদলাই →
ডিপ্লয় করি → যাচাই করি → **MX রেকর্ডও যোগ করে দিই (ইমেইলের জন্য)**।

## 🔐 নিরাপত্তা — একটা কাজ

লেখা আছে। কাজ শেষ হলে **বাতিল (revoke) করে দিন**:

1. **https://myaccount.google.com/apppasswords** → ওই password-এর পাশে **Delete** 🗑️
2. (ঐচ্ছিক) **https://myaccount.google.com/security** → **2-Step Verification** →
   **App passwords** → **Turn off**

**আমি কখনো কোনো password রিপোজিটরিতে লিখিনি** — সব `.secrets.env` ফাইলে আছে, যেটা
`.gitignore`-এ (`git status` পরিষ্কার ✅)।
