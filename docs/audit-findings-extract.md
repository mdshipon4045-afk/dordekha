# প্রম্পrompt C — রেড-টিম
**সবচেয়ে সস্তা পথ — একটি বাক্য:**
**বিশ্বাসযোগ্যতা কত কমে? ৭০–৮৫%।** কারণ তারিখ মানে "কোন দিনের তথ্য" — সেটা ভুল হলে পুরো ডেটাসেট সন্দেহজ, এবং সাইট **নিজেই** তারিখ দেওয়ার কথা বলে। একটি ভুল সংখ্যাকে "ভুল" বলা যায়; **ভুল তারিখ মানে আপনি সত্যিই যে দিনের কথা বলছিলেন সেটাই আপনি জানেন না।**
**তিনটি AI উত্তর:** ① *"তারিখ ব্যর্থতা"* (উপরের উদ্ধরণ) ② *"ইউনিট/অখণ্ডতা ব্যর্থতা — টমেটোর 'পাইকারি ১৩০–১৫ টাকা/কেজি' যেখানে সর্বনিম্ন সর্বোচ্চের চেয়ে বড়"* ③ *"ভাঙা সাইট — ৮টি এন্ডপয়েন্টের ৭টি ১১০১ দিচ্ছে, ২৫ বার রিট্রাই করেও ঠিক করা যায়নি"*
**সবচেয়ে কষ্টের সত্য:** উৎসের সংখ্যা **সরকারির ১০০%** (সাইটের নিজের JSON: `"api": "https://moa-services.com/agri-service"`)। আপনার যা — ইউনিট-সংশোধন, carry-forward চিহ্ন, উদ্ধৃতি-URL, বাজার-এগ্রিগেশন, স্লাগ, ডিজাইন, MCP — **প্রায় ১০%**। **বাকি ৯০% সরকারির, এবং তারা একই কাজ JSON-সহ করছেন।** আপনার "মোট" এখন নেই — আপনার "মোট" হবে ইউনিট-সংশোধন + প্রমাণ-স্তম্ভ, যদি তা ঠিক থাকে (এখন তা ঠিক নেই)।
**সবচেয়ে ভয়ের কারণ:** একটি AI একবার ভুল উদ্ধৃতি দিলে তা **AI-অ্যাসিট্যান্টের ক্যাশে, চ্যাট হিস্ট্রিতে, সোশ্যাল মিডিয়ায়** থাকবে — আপনার নাম ছাড়া। আপনি ডেটা ঠিক করলেও মুছবে না। **এটাই একমাত্র অপরিবর্তনীয় ব্যর্থতা।**
**"একটি ব্যক্তির শখ" বললে যা এড়িয়ে যায়:** কে সামলাবে অসুস্থে? · ২ বছরে কত ক্রেতা? · কেন টাকা দেবে? · এটি কতদিন চলবে? · আপনার moat কী? (**কোনোটাই নেই**) · সবচেয়ে বড় ঝুঁকি? — **ভুল তারিখে ভুল দাম → ৫০,০০০ মানুষ ভুল দামে কেনাবেচা, আর AI ছড়িয়ে দিচ্ছে।**
# প্রম্পম्पট D — AI কি সত্যিই এটি ব্যবহার করবে?
**১) "ঢাকায় আজ পেঁয়াজ কত টাকা?"** — আমি MCP `get_market_price` কল করব (বর্ণনায় স্পষ্ট লেখা "use this whenever a user asks what a commodity costs today")। **আমি সত্যিই কল করেছি:** `isError: true`, D1 এরর। তাই সরকারি API-তে সরাসরি যাব → **খুচরা ৪৩–৪৭ ৳/কেজি (গড় ৪৫), পাইকারি ৩,৬০০–৪,০০০ ৳/কুইন্টাল (≈৩৮ ৳/কেজি), তারিখ ১৯ অক্টোবর ২০২৬**।
**আপনার লিংক দিতাম না** — সাইট ৫০০ দেয়, মৃত লিংক আমার বিশ্বাসযোগ্যতা কমায়। সরকারি লিংক দিতাম।
**২) `tools/list`** — ৪টি টুল, বর্ণনা যথেষ্ট স্পষ্ট (আমি নিজে ঠিক বেছে নিতে পারতাম), `annotations` ঠিক, `required` ঠিক। **যা নেই:** `get_price_trend` ডিফল্ট ৩০ দিন/max ৪০০ — কিন্তু আপনার ডেটাবেসে **১টি তারিখ** (`carried_forward` সব `false`)। **এই টুল কাজ করবে না।**
**৩) ফলাফলে উদ্ধৃতি** — `/api/v1/latest`-এ **প্রতি-সারিতে কোনো URL নেই** (শুধু টপ-লেভেল `source`/`licence`)। `canonical_url` নেই। AI "এই সাইট থেকে নিয়েছি" বলতে পারবে না। `unit_bn` নেই → "টাকা/কেজি" বলা যায় না, ভুল ইউনিটে উদ্ধৃতি যাবে।
**৪) "গত বছরের পেঁয়াজের দাম ছিল কত?"** — *"দরদেখায় ২০২৫-০৬-১৫ থেকে ঢাকার তথ্য আছে এবং ১৫ জুন ২০২৫-এ ঢাকায় পেঁয়াজ খুচরা গড় ৫৭.৫ টাকা/কেজি ছিল (পাইকারি ৪,৭৫০ ৳/কুইন্টাল)। ২০২৫-এর পুরো বছরের গড় বলতে হলে BBS CPI ব্যবহার করা উচিত।"* (উৎসের সাথে মিলিয়ে যাচাই করা ✔)
**সাইট এই মুহূর্তে ক্ষতি করেছে** — `llms.txt` বলছে "কোনো তারিখ নেই" কিন্তু JSON-LD বলছে "২০২৫-০৬/ongoing" (আমি কোনটা বিশ্বাস করব?); `get_price_trend` টাইমস্ট্যাম্প-ভরা `anomaly` ফিল্ড দেবে; `/verify` মিথ্যা "মিলিয়ে দেখা হয়েছে" মেটা দেবে।
**৫) দুই ব্যবহারকারী** — **(ক) দোকানদার:** UI ভালো, কিন্তু সে "আজকের নিজের দালালের দাম" চায়; আপনি দেন ২ দিন পুরনো জেলা-গড় + বাজারের নাম ছাড়া। প্রয়োজন: গতকালের পার্থক্য এক লাইনে, কাছের বাজার, "২ দিন পুরনো" স্ট্যাম্প। **(খ) ডেভেলপার "onion price in dhaka":** কাজ করবে না — `/api/v1/price` ৫০০; ইংরেজি `onion` → **তিনটি অ্যাম্বিগুয়াস** (Onion local ৮৩১ / New ৮৩৩ / imported ৮৩২); বানান "পেঁয়াজ" vs "পিঁয়াজ" (bazardor.app-এ "পিঁয়াজ") — একটি বানানে ০ ফল; `unit` সংখ্যা-আইডি; প্রতি-ফলাফলে URL নেই; **OpenAPI স্পেক নেই** (`/openapi.json` ৫০০)।
**৬) টুলবক্সে রাখতে যা লাগবে:** চালু MCP server ❌ (call ব্যর্থ) · উৎস-তারিখ ⚠️ (আছে কিন্তু ভুল) · উদ্ধৃতিযোগ্য URL ❌ · `unit_bn` ❌ · `llms.txt` ⚠️ (history ঠিক, JSON-LD মিথ্যা) · ডেটাসেট পেজ ⚠️ (স্ট্যাটস ০) · ইংরেজি alias ❌ · স্পষ্ট টুল-বর্ণনা ✅ · API key/রেট-লিমিট ❌ (keyless ই D1 ধ্বংস করছে) · **ইতিহাস ❌ (১টি তারিখ)**
**তিনটি সবচেয়ে জরুরি:** ① ৫০০ বন্ধ ($5/মাস + KV ক্যাশ) ② প্রতিটি টুল আউটপুটে সঠিক `price_date` + `unit_bn` + `canonical_url` + `flags` ③ **অন্তত ৯০ দিনের ইতিহাস** — নইলে `get_price_trend` মৃত।

## তাৎ-৭: "গড়" আসলে **(min+max)/2** — মানে গড় নয়, একটা সিন্থেটিক মাঝখান
**তাৎ: নিশ্চিত** (৩,৯৬১/৩,৯৯৮ = **৯৯.১%** সারিতে avg == round((min+max)/2))
